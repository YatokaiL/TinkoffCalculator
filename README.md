# 🧮 Tinkoff Calculator

## 🎯 Цель  
Реализация полноценного мобильного приложения-калькулятора на **Swift** с поддержкой анимаций, истории вычислений и современного интерфейса.

---

## ⚙️ Правила работы приложения  
1. Пользователь может выполнять арифметические операции через удобный интерфейс.  
2. Поддерживаются базовые операции: **сложение**, **вычитание**, **умножение**, **деление**.  
3. Приложение корректно обрабатывает ввод выражений с десятичными числами и скобками.  
4. После каждого вычисления результат сохраняется в **историю**.  
5. Историю можно **просмотреть** и **очистить** при необходимости.  
6. В интерфейсе реализованы **плавные анимации** при нажатиях и обновлении значений.  
7. Ошибочные выражения (например, деление на ноль или некорректный ввод) не выполняются — отображается сообщение об ошибке.

---

## 💡 Функциональность приложения  
- Выполнение стандартных математических операций.  
- Поддержка работы с отрицательными и дробными числами.  
- История всех вычислений с возможностью повторного использования результата.  
- Очистка поля ввода и истории.  
- Анимированные переходы между состояниями интерфейса.  
- Адаптивный дизайн под разные размеры экранов.  
- Поддержка **тёмной** и **светлой** темы.  

---

## 📱 Пример работы  
1. Пользователь вводит выражение `12 + 8 × 2` и нажимает `=`.  
   - На экране появляется результат: **28**.  
   - Выражение сохраняется в истории.  
2. Пользователь открывает историю и выбирает предыдущее выражение — оно автоматически подставляется в поле ввода.  
3. При делении на ноль (`5 ÷ 0`) отображается анимация ошибки и сообщение:  
   > **Ошибка: деление на ноль**  
4. После очистки истории все прошлые вычисления исчезают, интерфейс возвращается к начальному состоянию.

## 🧱 Технологии проекта  
- **Swift / SwiftUI / UIKit**  
- **MVVM-архитектура**  
- **Combine / Core Animation** для анимаций  
- **UserDefaults / Core Data** для хранения истории  
- **Auto Layout / SwiftUI Layout System** для адаптивного интерфейса  
- Поддержка **iOS 15+**
