Калькулятор для iOS на Swift и UIKit (учебный проект, 2024). Четыре арифметических действия,
дробные числа через запятую, цепочки операций и обработка деления на ноль.

## Возможности

| № | Функция | Что умеет |
|---|---|---|
| 1 | Ввод числа | цифры и десятичная запятая, вторую запятую поставить нельзя, ведущий ноль заменяется |
| 2 | Операции | сложение, вычитание, умножение, деление |
| 3 | Цепочки | несколько операций подряд, например `2 + 3 × 4 − 1` |
| 4 | Ошибки | при делении на ноль на экране появляется `Error` |
| 5 | Сброс | кнопка `C` очищает ввод и все накопленные операции |

## Как устроено

- `Operation` — enum с операциями `+ − × ÷`, метод `calculate` выполняет действие и бросает
  `CaluclationError.divideByZero` при делении на ноль.
- `CalculationHistoryItem` — enum `.number(Double)` / `.operation(Operation)`. Пока пользователь вводит
  выражение, числа и операции складываются в массив `calculationHistory`.
- По нажатию `=` массив проходится парами «операция + число», результат считается последовательно
  **слева направо**: `12 + 8 × 2 = 40`.
- Число на экране парсится и форматируется через `NumberFormatter` с локалью `ru_RU`, поэтому
  десятичный разделитель — запятая.
- Интерфейс свёрстан в `Main.storyboard`, кнопки подключены через `@IBAction`.

## Запуск

1. Открыть `TinkoffCalculator.xcodeproj` в Xcode.
2. Выбрать симулятор iPhone.
3. Нажать `Cmd + R`.
